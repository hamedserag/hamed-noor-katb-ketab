# كتب كتاب حامد ونور

دعوة عربية رقمية متجاوبة لكتب كتاب حامد ونور في مسجد قصر محمد علي بالمنيل يوم 3 أكتوبر 2026.

## التشغيل

لا توجد خطوة بناء. افتح `index.html` مباشرة، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## التخصيص

- عدّل رابط Google Maps داخل `index.html`.
- ضع الصور داخل مجلد `assets` واستبدل العناصر المؤقتة بصور فعلية.
- ضع ملف الموسيقى باسم `assets/music.mp3` ثم أضف المسار إلى عنصر `audio`.
- نموذج RSVP الحالي يحفظ الردود في `localStorage` على جهاز الضيف فقط؛ يحتاج Backend أو خدمة Forms قبل الاستخدام الحقيقي.

## النشر عبر GitHub Pages

من إعدادات المستودع:

1. افتح **Settings → Pages**.
2. اختر **Deploy from a branch**.
3. اختر فرع `main` والمجلد `/root`.
4. احفظ الإعدادات.
