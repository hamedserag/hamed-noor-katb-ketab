# كتب كتاب حامد ونور

دعوة عربية رقمية متجاوبة لكتب كتاب حامد ونور في مسجد قصر محمد علي بالمنيل يوم 3 أكتوبر 2026.

## المكونات

- واجهة الدعوة والألبوم العام.
- PHP/MySQL لتأكيد الحضور ورفع الصور.
- لوحة إدارة محمية تحت `/admin/`.
- مراجعة صور الضيوف قبل النشر.
- سلة صور قابلة للاستعادة مع حذف نهائي اختياري.
- تصنيف هادئ للردود المشتبه بها دون رفض ردود الضيوف تلقائيًا.

## دورة حياة صور الضيوف

1. يرفع الضيف الصورة من صفحة الدعوة.
2. يحفظ PHP الصورة داخل المجلد المحمي:

   `uploads/pending/guest-photos/`

3. تظهر الصورة في **لوحة الإدارة → مراجعة الصور** فقط.
4. عند الاعتماد تنتقل فعليًا إلى:

   `uploads/guest-photos/`

   ثم تظهر في الألبوم العام.
5. عند الإزالة تنتقل إلى:

   `uploads/bin/guest-photos/`

6. من سلة الصور يستطيع المدير:
   - استعادة صورة الضيف إلى قائمة المراجعة.
   - حذف الملف وسجل قاعدة البيانات نهائيًا بعد التأكيد.

صور الإدارة المنشورة تحفظ في `uploads/gallery/`، وعند إزالتها تنتقل إلى `uploads/bin/site-images/`.

`uploads/pending/.htaccess` و`uploads/bin/.htaccess` يمنعان الوصول العام المباشر. لوحة الإدارة تعرض الملفات من خلال `admin/media.php` بعد التحقق من جلسة المدير.

## الألبوم العام

`api/images.php` يعيد فقط:

- صور الإدارة النشطة والمعتمدة.
- صور الضيوف التي تحمل حالة `approved` و`is_visible = 1`.

تعرض الصفحة عددًا محدودًا من الصور في تدفق مرن يحافظ على نسبة أبعاد الصورة. زر **عرض الألبوم كاملًا** يفتح معرضًا بملء الشاشة، مع عارض صورة وتنقل سابق/تالٍ.

## لوحة الإدارة

الأقسام الرئيسية:

- **نظرة عامة:** الردود السليمة، عدد الحضور، الصور المعلقة، الاشتباه بالرسائل المزعجة.
- **مراجعة الصور:** اعتماد صورة الضيف أو نقلها إلى السلة.
- **الألبوم:** إدارة الصور المنشورة ورفع صور الإدارة.
- **الحضور:** البحث والتصفية والحذف وتعليم الرد كسليم أو مزعج.
- **السلة:** استعادة الصور أو حذفها نهائيًا.

كل عمليات الكتابة تستخدم جلسة مدير، CSRF token، وطلبات POST. الإزالة والحذف النهائي يحتاجان تأكيدًا من الواجهة.

## اكتشاف الردود المزعجة

لا يرفض النظام أي RSVP صالح تلقائيًا. يسجل الرد أولًا ثم يحسب درجة اشتباه اعتمادًا على مؤشرات محدودة:

- تكرار نفس الرد خلال 30 دقيقة.
- وجود روابط في الاسم أو عدة روابط في الرسالة.
- تكرار غير طبيعي للحروف.
- اسم لا يحتوي على حروف.
- User-Agent آلي معروف.

عند بلوغ `spam_score_threshold` يظهر الرد كمشتبه به في لوحة الإدارة، ويمكن للمدير اعتباره سليمًا أو حذفه. القيمة الافتراضية:

```php
'spam_score_threshold' => 4,
```

## قاعدة البيانات والترقية

`server/schema.sql` يحتوي مخطط التثبيت الجديد. عند تحديث موقع قائم، `ensure_runtime_schema()` يضيف الأعمدة والفهارس المطلوبة دون حذف البيانات الحالية.

الترقية تحافظ على صور الضيوف المنشورة سابقًا وتعتبرها معتمدة إذا كانت `upload_status = 'uploaded'` و`is_visible = 1`.

الجداول:

- `admin_users`
- `rsvp_responses`
- `site_images`
- `guest_photo_uploads`

## النشر على Hostinger

1. خذ نسخة احتياطية من ملفات الموقع وقاعدة البيانات.
2. احتفظ بنسخة من `server/config.local.php`.
3. استخرج حزمة التحديث داخل `public_html` مع استبدال ملفات الكود.
4. لا تحذف `uploads/` ولا تستبدل `server/config.local.php`.
5. تأكد أن مجلد `uploads/` قابل للكتابة بواسطة PHP؛ الإعداد المعتاد `755` للمجلدات و`644` للملفات.
6. افتح `/admin/` مرة واحدة لتشغيل الترقية، ثم راجع أقسام الصور والحضور.
7. ارفع صورة ضيف تجريبية وتأكد أنها لا تظهر للعامة قبل الاعتماد.
8. اعتمدها من لوحة الإدارة وتأكد أنها تظهر في الألبوم.
9. انقلها إلى السلة، اختبر الاستعادة، ثم احذف صورة اختبار غير مهمة نهائيًا.

ملف `server/config.local.php` مستبعد من Git ويجب ألا يحتوي المستودع أو حزمة النشر على بيانات MySQL الفعلية.

## متطلبات PHP

استخدم PHP 8.x مع:

- PDO MySQL
- mbstring
- fileinfo

وتأكد أن `upload_max_filesize` و`post_max_size` يسمحان برفع 10 MB على الأقل للصورة.

## المعاينة الثابتة

```bash
python -m http.server 8080
```

المعاينة الثابتة لا تشغل PHP أو MySQL أو رفع الملفات.
