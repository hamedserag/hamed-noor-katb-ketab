# كتب كتاب حامد ونور

دعوة عربية رقمية متجاوبة لكتب كتاب حامد ونور في مسجد قصر محمد علي بالمنيل يوم 3 أكتوبر 2026.

## الوضع الحالي

- الواجهة الأمامية تعمل كصفحة ثابتة ويمكن معاينتها عبر GitHub Pages.
- على Hostinger يتم تفعيل Backend PHP/MySQL لتأكيد الحضور.
- لوحة الإدارة موجودة تحت `/admin/`.
- يمكن للمدير مشاهدة الردود، إجمالي الحضور، تصدير CSV، ورفع صور جديدة إلى معرض الدعوة.

## نشر النسخة الكاملة على Hostinger

1. أنشئ قاعدة MySQL ومستخدمًا لها من hPanel في Hostinger.
2. انسخ `server/config.example.php` إلى `server/config.local.php` على الخادم.
3. ضع بيانات قاعدة البيانات الفعلية في `server/config.local.php`.
4. انشر محتويات المستودع داخل `public_html` أو مجلد الموقع المطلوب.
5. افتح `/admin/`.
6. اضغط **إنشاء الجداول** لإنشاء جداول RSVP والمستخدمين والصور.
7. أنشئ أول حساب مدير بكلمة مرور قوية.
8. اختبر نموذج **تأكيد الحضور** من الصفحة الرئيسية، ثم تحقق من ظهوره في لوحة الإدارة.

> ملف `server/config.local.php` مستبعد من Git ولا يجب رفع كلمات مرور قاعدة البيانات إلى المستودع.

## قاعدة البيانات

المخطط موجود في:

`server/schema.sql`

ويحتوي على:

- `admin_users`
- `rsvp_responses`
- `site_images`

يمكن للوحة الإدارة إنشاء هذه الجداول تلقائيًا بعد نجاح الاتصال بقاعدة MySQL.

## رفع الصور

من `/admin/` يمكن رفع صور JPG / PNG / WebP، وإضافة:

- تعليق يظهر أسفل الصورة.
- وصف بديل للصورة.
- ترتيب العرض.

الصور تحفظ فعليًا في `uploads/`، وبياناتها تحفظ في MySQL، ثم يتم تحميلها تلقائيًا داخل معرض الدعوة.

## تأكيد الحضور

عند النشر على Hostinger يرسل النموذج البيانات إلى:

`api/rsvp.php`

وتحفظ في جدول `rsvp_responses`.

على GitHub Pages فقط، لأن PHP غير مدعوم، يبقى السلوك كنسخة معاينة ويحفظ الرد محليًا على جهاز المتصفح بدل قاعدة البيانات.

## متطلبات PHP

يوصى بـ PHP 8.x مع الإضافات التالية مفعلة:

- PDO MySQL
- mbstring
- fileinfo

## التشغيل كواجهة ثابتة فقط

يمكن تشغيل نسخة المعاينة محليًا بدون PHP:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.
